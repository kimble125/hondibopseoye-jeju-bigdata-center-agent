# 혼디봅서예

> 처음 가는 데이터센터, 걱정 대신 기대로
>
> 제주 AI·빅데이터 활용 AI Agent 개발 챌린지 · 팀 요망진조

제주빅데이터센터를 처음 찾는 사람의 동행 에이전트입니다. 가기 전에는 센터 데이터를 둘러보고, 센터에서는 받은 CSV로 초안을 만들고 문장을 검산하고, 나올 때는 검수받기 좋은 반출 신청 자료를 준비합니다. 안내는 고래 사서 '고랑이'가 맡습니다.

- **대상:** 센터를 처음 찾는 예비 창업자와 소상공인, 기업·기관의 비IT 담당자
- **범위:** 깊은 분석은 센터에서 가장 많이 찾는 카드 데이터에 집중했습니다. 그 밖의 CSV는 범용 요약만 합니다. 예측과 원인 추정은 하지 않습니다.
- **상태:** macOS·Chrome에서 모든 기능을 확인했고 정답표 검증을 통과했습니다. Windows PC 실행과 실제 센터 CSV는 확인하지 못했습니다. [구현 상태](#구현-상태)를 함께 봐 주세요.
- **체험:** [웹 체험판](https://kimble125.github.io/hondibopseoye-jeju-bigdata-center-agent/) (준비한 문장만 답하고 파일 올리기는 안 됩니다) · [소개 영상](https://youtu.be/X863_sNQ28E)

## 동작 흐름

```mermaid
flowchart LR
  A[① 이해<br>문서·업종·지역·기간·주장] --> B[② 자료 확인<br>표 종류, 있는 달, 지역 칸]
  B -->|자료 부족| R[받을 표와 달 안내]
  B --> C[③ 계획<br>요약·비교·전년 대비·순위·틀]
  C --> D[④ 계산<br>정해진 규칙]
  D --> E[⑤ 사전 점검<br>10 미만·역산 가림]
  E --> F[⑥ 판정<br>써도 됨·고쳐 쓰기·쓸 수 없음]
  F --> G[⑦ 작성<br>문장, 근거 한 장, 다음 제안]
```

실행 중 외부 AI와 외부 API를 부르지 않습니다. 센터 데이터는 밖으로 보낼 수 없어서, 판단과 계산을 PC 안의 규칙으로 구현했습니다.

## 주요 기능

| 방문 순서 | 기능 | 내용 |
| --- | --- | --- |
| ① 가기 전에 | 데이터 둘러보기 | 센터 데이터 71종의 설명, 칸 이름, 반출 조건을 집에서도 봅니다. |
| | 받을 자료 추천 | 쓰려는 문서, 업종, 지역을 고르면 받을 표와 받는 법을 알려 줍니다. |
| | 센터 이용 안내 | 예약부터 반출까지의 센터 규칙을 출처와 함께 보여 줍니다. |
| ② 센터에서 | CSV 넣기 | 내려받은 파일을 그대로 넣으면 어떤 표인지 알아보고 진단합니다. |
| | 문서 초안 | 사업계획서 시장·고객 현황, 월간 소비동향, 자료 요약 한 장. |
| | 문장 검산 | 써도 됩니다 / 이렇게 고쳐 쓰세요 / 이 자료로는 쓸 수 없습니다. 모호하면 되묻습니다. |
| ③ 가져갈 때 | 반출 신청 전 점검 | 10 미만 값과 역산될 합계를 가리고 '반출 신청용 점검 요약'을 붙입니다. |
| ④ 기다리는 동안 | 결과 안내, 퇴실 정리 | 결과가 언제 어떻게 오는지 알려 주고, 넣은 파일과 결과를 지웁니다. |

## 구현 상태

| 부분 | 상태 |
| --- | --- |
| 문장 검산 | 구현. 정답표 26문항 통과(실제 공개 데이터 20, 가상 센터 데이터 6), 두 번 실행해 출력 동일 |
| 문서 초안, 요약, 추천 | 구현. 정답표 11문항 통과 |
| 가림, 점검 요약, 퇴실 정리 | 구현. 단위 시험 106개, 화면 시험 49개 항목 통과 |
| 카드 밖 데이터의 전용 틀 | 얼개와 범용 요약까지 |
| Windows PC 실행 | 확인하지 못함(개발과 확인은 macOS·Chrome). `run.bat`은 Windows 규칙에 맞춰 작성 |
| 실제 센터 CSV | 확인하지 못함. 형식이 같은 가상 데이터(`SYNTHETIC_`)로 시연 |
| 외부 언어 모델 층 | 구현하지 않음. 센터가 기준을 정하면 붙일 수 있는 구조 |

## 실행

Python 3.12 이상 하나만 있으면 됩니다. 추가 패키지는 없습니다.

```
git clone https://github.com/kimble125/hondibopseoye-jeju-bigdata-center-agent.git
cd hondibopseoye-jeju-bigdata-center-agent
python run.py            # Windows는 run.bat 두 번 누르기
python -m evm.evalrun --golden eval/golden_card.json   # 정답표 검증
```

제주데이터허브 원본 CSV 4종은 재배포가 제한되어 이 저장소에 없습니다. 받는 법과 자세한 사용법은 [매뉴얼](MANUAL.md)에 있습니다.

## 데이터와 개인정보

- 넣은 파일은 메모리에만 두고 저장하거나 전송하지 않습니다. 프로그램은 `127.0.0.1` 안에서만 응답합니다.
- 쓰는 데이터는 제주데이터허브 공개 카드 데이터 4종, 센터 데이터 명세서(공개), 가상 데이터입니다. 자세한 내용은 [데이터 활용 명세](DATA_USE.md)에 있습니다.
- 반출 사전 점검은 센터의 심사를 대신하지 않습니다. 승인 여부는 센터가 정합니다.
