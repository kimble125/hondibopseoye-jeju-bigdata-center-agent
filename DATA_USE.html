6. 전처리와 분석 흐름

  1. 읽기. CSV의 머리글로 어떤 표인지 알아봅니다(허브 공개 표, 센터 카드 표 3종, 그 밖의 표). 읽을 때 BOM과 큰따옴표를 벗기고, 덧붙은 칸(pt_year, pt_month 등)은 무시합니다. 원본 파일은 고치지 않습니다.
  2. 건너뛰기. 이용자수·건수·금액이 정수가 아닌 줄(NA, 빈칸, NULL)은 건너뛰고, 건너뛴 줄 수를 화면에 보여 줍니다. 묶음에 든 공개 파일에는 그런 줄이 없습니다(0줄).
  3. 이용자 구분 묶기. 도민 = 제주도민 / 내국인 관광객 = 내국인 / 외국인 = 중국·일본·동남아·기타외국 / 법인 = 법인 / 관광객 전체 = 내국인 관광객 + 외국인.
  4. 계산(정해진 규칙만). 조건에 맞는 줄의 합계(원 단위 정수), 고객 구성 비중, 대상 비교(차이와 비율), 전년 같은 달 대비, 순위. 비율은 한 번만 반올림합니다(문장 검산은 소수 첫째 자리, 소비동향 틀은 원 리포트처럼 둘째 자리). 계산할 수 없는 값과 가린 값은 숫자 대신 빈 값으로 둡니다.
  5. 반출 사전 점검(센터 카드 표 세 종류에만). 묶음의 이용자수·건수·금액 합계 가운데 가장 작은 값이 10 미만이면 그 묶음을 가리고, 하나라도 가리면 합계와 모든 비중을 함께 가립니다(가린 값을 합계로 되살릴 수 없게). 인쇄하는 쪽은 전체를 한 번 더 검사합니다.
  6. 문장. 계산 결과를 정해진 문장 틀에 넣고, 문장 속 숫자가 계산 결과(와 기간, 고정 기준값)에 있는 값인지 검사합니다. 계산에 없는 숫자가 있으면 그 문장을 버립니다.
  7. 출처 문구. 모든 숫자 답에 출처: <제공처>, <데이터 이름>(<기간>) 과 계산식을 붙입니다.

이용자가 넣은 파일은 이 PC의 메모리에서만 다루고, 디스크에 저장하지 않으며 어디로도 보내지 않습니다. '퇴실 정리'를 누르거나 프로그램을 끄면 사라집니다.

오픈소스·외부 코드없음. Python 표준 라이브러리만 씁니다(추가 패키지 0개)
데이터 API부르지 않습니다. 공개 데이터는 파일로 묶음에 들어 있어 데이터 API 키가 필요 없습니다
외부 AI API외부 AI API: 부르지 않습니다. 규칙으로 읽지 못한 자유로운 문장을 언어 모델로 다시 쓰는 층은 설계만 해 두고 이번 제출물에는 넣지 않았습니다. 센터가 외부 전송 기준을 정하면 붙일 수 있는 자리(문장 이해 앞, 사전 점검을 통과한 결과 뒤)만 남겨 두었습니다.
개발에 쓴 AI 도구설계·문서·검증: Aside(AI 브라우저 에이전트, Claude Fable 5.2) / 구현: Aside의 하위 작업(Claude Opus 5.5)이 설계서와 정답표를 받아 코드 작성 / 독립 검토: GPT-6.2 Astra / 주제 검토: Gemini 4(웹) / 자료 조사 보조: Claude Sonnet 5.5 / 캐릭터 그림(고래 사서): ChatGPT 이미지 생성. 참가자가 문제와 범위를 정하고 결과를 검수했습니다
실행 확인 환경macOS(Python 3.14, Chrome). Windows PC에서의 실행은 마감 전에 확인하지 못했습니다

8. 제출물에 넣지 않은 것

  • 대회가 준 「제주데이터허브 데이터 목록」 엑셀과 예시 데이터 엑셀, 그리고 그 파일에서 만든 자료
  • 실제 제주빅데이터센터 데이터(원본, 발췌, 집계 결과 모두)
  • API 키와 비밀값(키를 쓰는 기능이 없고, 설정 파일도 넣지 않았습니다)
  • 개인정보(묶음의 데이터는 공개 집계 자료와 가상 데이터뿐입니다)
