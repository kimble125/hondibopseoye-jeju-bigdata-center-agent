혼디봅서예

처음 가는 데이터센터, 걱정 대신 기대로

「제주 AI·빅데이터 활용 AI Agent 개발 챌린지」 제출작입니다. 제주빅데이터센터에 처음 가는 사람이 ① 가기 전에 어떤 데이터가 있는지 둘러보고 ② 센터에서 받은 CSV로 문서 초안을 만들고 쓰려는 문장을 검산하고 ③ 반출 신청 전에 가릴 숫자를 가리고 ④ 결과를 기다리는 동안 무엇을 하면 되는지까지 돕는 로컬 웹 에이전트입니다.

  • 인터넷과 API 키 없이 모든 기능이 동작합니다.
  • 설치할 프로그램은 Python 3.12 이상 하나입니다. 추가 패키지를 받지 않습니다.
  • 넣은 파일은 이 PC의 메모리에서만 계산하고, 저장하거나 밖으로 보내지 않습니다.

함께 든 문서: DATA_USE.md(데이터 활용 명세), RESULT_NOTES.md(결과 설명자료). 같은 내용을 브라우저로 보기 편하게 README.html, DATA_USE.html, RESULT_NOTES.html 로도 넣었습니다.

1. 3분 실행

걸음 1. Python 설치(이미 3.12 이상이 있으면 건너뜁니다)

  1. https://www.python.org/downloads/ 에서 Windows용 설치 파일을 내려받아 실행합니다. 지금 배포되는 'Python install manager'는 'Install'을 누르면 되고, Microsoft Store에서 'Python Install Manager'를 설치해도 같습니다. 예전 방식의 설치 파일(python-3.x.x-amd64.exe)이면 기본값으로 설치하고, 'Add python.exe to PATH' 칸이 보이면 체크합니다.
  2. 확인: 시작 메뉴에서 '명령 프롬프트'를 열고 py --version 을 입력합니다. Python 3.12 이상의 숫자가 나오면 됩니다(py 가 없다고 나오면 python --version). Python install manager는 처음 실행할 때 최신 Python을 한 번 내려받습니다(이때만 인터넷이 필요합니다).
  3. 설치하는 것은 Python 하나뿐입니다. pip install 같은 추가 설치는 하지 않습니다.

걸음 2. 압축 풀기

ZIP을 아무 폴더에나 풉니다. 한글이나 빈칸이 든 경로도 됩니다(예: C:\Users\사용자\Desktop\jeju-evidence-mate).

걸음 3. run.bat 두 번 누르기

  • 검은 창에 준비되었습니다: http://127.0.0.1:8765/ 가 나오고, 기본 브라우저에 화면이 열립니다.
  • 브라우저가 저절로 열리지 않으면 Chrome이나 Edge 주소창에 http://127.0.0.1:8765/ 를 입력합니다.
  • 끝낼 때는 검은 창을 닫거나 그 창에서 Ctrl+C 를 누릅니다.

macOS·Linux에서는 터미널에서 python3 run.py 를 실행합니다(Python 3.12 이상).

화면은 왼쪽(첫 화면, 문장 확인하기, 문서 초안)과 오른쪽(자료 현황판)으로 나뉩니다. 처음 켜면 제주데이터허브의 공개 카드 데이터(실제 값, 2018년 1월–2025년 6월)가 이미 들어 있습니다.

3. 사용자 매뉴얼

3-1. 가기 전에(집 PC에서도 됩니다)

  • 데이터 둘러보기: 센터 데이터 71종의 이름, 설명, 칸 이름(한글·영문), 예시, 반출 조건을 검색하거나 분야별로 봅니다. '많이 찾는 데이터' 칩은 센터 화면의 2026년 검색·반출 상위 목록입니다. 여기서 보는 것은 공개된 명세서의 설명이고, 데이터 자체는 센터에 가야 받을 수 있습니다.
  • 받을 자료 메모: '받을 목록에 담기'로 모은 표의 이름과 받는 법을 복사하거나 인쇄해 센터에 가져갑니다.
  • 받을 자료 추천: '처음 오셨나요?' 카드에서 고르거나, 문장 칸에 카페 창업 사업계획서를 쓰려는데 어떤 자료를 받아야 하나요 처럼 묻습니다.
  • 센터 이용 안내: 예약, 가져올 수 있는 것, 자료 받기, 반출 신청, 기다리기, 퇴실까지. 항목마다 출처가 있고, 확인하지 못한 것은 '아직 확인되지 않은 것'에 따로 있습니다. 현장 안내가 다르면 센터 안내를 따르세요.

3-2. 센터에서: CSV 넣기

  • 오른쪽 'CSV 파일 넣기' 로 센터 시스템에서 내려받은 파일(Results_날짜_시간.csv)을 그대로 넣습니다. 이름을 바꾸거나 열어서 고칠 필요가 없습니다.
  • 머리글로 어떤 표인지 알아봅니다: 「카드 이용 현황(읍면동)_v02」, 「(요일별)_v02」, 「(시간대)_v02」, 허브 공개 표. 카드 표는 같은 종류의 파일을 여러 개(예: 달마다 하나씩) 넣으면 합쳐서 봅니다.
  • 그 밖의 표(버스, 폐기물 등)는 한 번에 한 파일씩 '자료 요약'(기간, 행 수, 숫자 칸의 합계와 범위, 주요 범주)만 해 줍니다. 이 요약에는 반출 사전 점검이 적용되지 않습니다(화면에도 그렇게 알립니다). 센터 자료라면 이 요약을 그대로 반출 신청에 쓰지 마세요.
  • 센터의 카드 표(위 세 종류)가 들어오면 반출 사전 점검이 켜집니다.
  • 파일 하나는 약 60MB까지 넣을 수 있습니다. 더 크면 기간이나 조건을 나눠 받아 주세요.

틀넣을 것나오는 것
사업계획서: 시장·고객 현황 칸업종(필수), 지역(선택, 센터 자료가 있을 때)시장 규모와 12개월 추이, 전년 같은 달 대비, 고객 구성, 성별·연령, 계절성, 요일·시간대 참고, 지역 상세
현황자료: 월간 소비동향달(예: 202506), 대상금월·전월·전년 같은 달 비교, 업종별 증감, 각주
자료 요약: 목적에 맞춘 한 장업종고객 구성 표, 전년 같은 달 대비
  • 초안마다 '본뜬 양식과 출처'가 적혀 있습니다. 초안은 공식 양식이 아닙니다.
  • 양식의 "경쟁 강도", "향후 전망" 칸은 채우지 않고 "이 자료로는 쓸 수 없습니다"와 필요한 자료를 적습니다.
  • 칸마다 '복사': 표는 탭으로 나뉜 글자로 복사됩니다. 엑셀에는 칸대로 붙고, 한글·워드에서는 붙인 뒤 '표로 변환' 기능을 쓰면 표가 됩니다. '전체 복사' 는 출처 줄까지 함께 복사합니다.

3-5. 가져갈 때: 반출 신청 전 점검

  • 센터 표에서 나온 결과는 이용자수·건수·금액 합계 가운데 가장 작은 값이 10 미만인 구분을 가리고("10 미만(가림)"), 하나라도 가리면 합계와 비중도 함께 가립니다.
  • '근거 한 장'과 문서 초안의 인쇄 화면 맨 위에 '반출 신청용 점검 요약'(원본 데이터, 가공 방법, 실린 수치, 10 미만 처리, 역산 점검, 그림, 원본·발췌, 활용 목적, 만든 도구)이 붙습니다. '활용 목적' 칸은 직접 채웁니다.
  • '인쇄 / PDF로 저장' 을 누르고 인쇄 창에서 'PDF로 저장'을 고르면 반출 신청에 첨부할 파일이 됩니다. 신청은 센터 시스템에서 직접 하며, 승인 여부는 센터가 정합니다. 이 프로그램은 승인을 보장하지 않습니다.
  • 센터 표가 쓰인 인쇄물에는 그림(차트)을 넣지 않습니다.

3-6. 퇴실 정리

'퇴실 정리(자료와 결과 지우기)' 를 누르면 넣은 파일, 만든 결과, 대화, 받을 자료 메모가 지워집니다. 지워진 결과의 주소를 다시 열면 '지워진 결과입니다'가 나옵니다. 따로 열어 둔 인쇄용 탭은 닫아 주세요. 직접 저장한 PDF, 내려받은 CSV, 복사해 둔 내용은 이 프로그램이 지우지 못하니 센터 안내에 따라 정리해 주세요.

6. 오류와 해결

증상해결
run.bat 을 눌렀더니 Python 3.12 or newer is requiredPython이 없거나 3.12보다 낮습니다. 1절 걸음 1대로 설치한 뒤 다시 누릅니다
8765번 포트를 다른 프로그램이 쓰고 있습니다이미 실행 중인 창이 있으면 그 창을 씁니다. 아니면 명령 프롬프트에서 run.bat --port 8766
브라우저가 열리지 않음주소창에 검은 창에 나온 주소(http://127.0.0.1:8765/)를 직접 입력
'Windows의 PC 보호' 같은 보안 경고 창센터 PC에서는 실행을 멈추고 운영자에게 확인해 주세요. 개인 PC에서는 '추가 정보' → '실행'으로 넘어갈 수 있습니다. run.bat 은 Python을 찾아 run.py 를 실행하는 몇 줄짜리 글자 파일입니다
CSV를 넣었더니 '자료 요약'만 나옴카드 표가 아닌 표입니다. 문장 검산과 틀 초안은 카드 이용 표에서 됩니다. '공개 카드 자료로 돌아가기'를 누르면 처음 상태가 됩니다
같은 파일을 두 번 넣었다는 안내내용이 같은 파일은 한 번만 넣습니다(행이 두 배로 세어지는 것을 막습니다)
"지금 넣은 자료에는 ○○○○년 ○월 값이 없습니다"그 달의 파일을 센터에서 받아 추가로 넣습니다
"이 자료로는 쓸 수 없습니다"예측, 원인, 업종 전체 매출, 점포 수는 이 자료로 답할 수 없습니다. 안내된 다른 자료가 필요합니다
글자가 깨져 보임센터 CSV는 UTF-8입니다. 엑셀로 열어 다시 저장한 파일이면 원래 내려받은 파일을 넣어 주세요
화면이 멈춘 것 같음검은 창이 닫혔는지 봅니다. 닫혔으면 run.bat 을 다시 누릅니다(넣었던 파일은 다시 넣어야 합니다)

7. 제약사항

  • 숫자는 비씨카드 결제분만 집계한 자료에서 나옵니다. 업종 전체 매출이 아닙니다.
  • 묶음에 든 공개 데이터는 2025년 6월까지입니다.
  • 참가자는 실제 센터 CSV를 보지 못했습니다. 센터 표의 형식은 공개 명세서와 대회 게시판 운영 답변에 맞췄고, 가상 데이터로 시험했습니다. 실제 파일에서의 동작은 확인되지 않았습니다.
  • 반출 사전 점검은 센터의 심사를 대신하지 않습니다.
  • 문장 이해는 규칙 기반입니다. 사전에 없는 표현은 되묻거나 예시를 제안합니다.
  • 문장 검산과 틀 초안은 카드 이용 표에서만 됩니다. 다른 표는 자료 요약과 받을 자료 추천까지이고, 그 자료 요약에는 반출 사전 점검이 적용되지 않습니다.
  • 이용자 수의 합은 서로 다른 사람의 수가 아닙니다(같은 사람이 여러 줄에 셀 수 있습니다).
  • 센터 이용 안내는 2026-11-19에 확인한 내용입니다.
  • 개발과 확인은 macOS(Python 3.14, Chrome)에서 했습니다. Windows PC에서의 실행은 마감 전에 확인하지 못했습니다.

9. 센터 운영자께

  • 탑재: ① Python 3.12 이상 설치 ② 이 폴더를 PC에 풀기 ③ 바탕화면에 run.bat 바로가기 만들기. 서명 없는 확장 모듈(.pyd, .dll)과 추가 패키지를 쓰지 않습니다.
  • 규칙이 바뀌면 inputs/center_guide.json 의 문장만 고치면 됩니다(항목마다 text, source). 데이터가 늘면 inputs/center_catalog.json, 추천과 틀은 inputs/report_catalog.json, 이름은 inputs/branding.json 입니다. 문장과 목록은 코드를 고치지 않고 바꿀 수 있습니다(계산식과 점검 기준을 바꿀 때는 코드 수정이 필요합니다).
  • 보존 스위치: 설정의 KEEP_RESULTS 는 기본 0 입니다. 어느 값이든 넣은 파일과 결과는 메모리에만 있고 프로그램을 끄면 사라집니다.
  • 이용 기록: 이 프로그램은 넣은 파일의 내용이나 문장을 기록 파일로 남기지 않습니다.
  • 외부 전송: 이 프로그램은 외부 주소에 접속하지 않습니다. 외부 AI를 부르는 기능이 없습니다.

10. AI 활용과 외부 자원 명시(대회 규칙 1)

항목내용
실행 중에 쓰는 AI 모델외부 AI 모델을 부르지 않습니다. 에이전트의 판단(이해, 자료 확인, 계획, 판정, 숫자 검사)은 이 PC 안의 규칙과 계산으로 동작합니다
개발에 쓴 AI 도구설계·문서·검증: Aside(AI 브라우저 에이전트, Claude Fable 5.2) / 구현: Aside의 하위 작업(Claude Opus 5.5)이 설계서와 정답표를 받아 코드 작성 / 독립 검토: GPT-6.2 Astra / 주제 검토: Gemini 4(웹) / 자료 조사 보조: Claude Sonnet 5.5 / 캐릭터 그림(고래 사서): ChatGPT 이미지 생성. 참가자가 문제와 범위를 정하고 결과를 검수했습니다
외부 API·서비스없음(외부 AI API, 데이터 API 모두 부르지 않습니다. 평가용 키가 필요 없습니다)
외부 데이터없음. 묶음의 데이터는 제주데이터허브 공개 데이터 4종과 가상 데이터 3개입니다(DATA_USE.md)
오픈소스·외부 코드없음(Python 표준 라이브러리만 사용)
데이터 API 키쓰지 않으므로 제출물에 없습니다
